## 2. 다음에 할 일 (우선순위 순)

1. **[결정 D1~D3 → 착수, L] 지도 위 전투 밸런스 재조정** — 고블린만 무리 3~4마리 99%. 구울·노움·칼날늑대는 2마리 이상이면 승률 0% 근처(`node web/tests/groupsim.js <id> 1 2 3`). 근본 원인: 몬스터 체력 100 / 플레이어 영혼력 20·지속 딜 ≈12/턴 → 한 마리에 8턴 이상. 함께 볼 것: 부위 손상 누적, 무기별 격차(방패 최약, 활·창은 거리 두기 미반영). `groupsim.js` 를 정식 시뮬레이터로 다듬고 근거를 `docs/implementation_notes.md` 에 남긴다.
2. **[착수, S] 플레이 피드백 확인** — 최근 변경(구울 하향, 선공 8칸, 부위 손상 유지, 적 탭 = 가장 강한 스킬, 고블린 약화)을 사용자가 플레이해 체감을 알려 줄 차례. 불편한 점은 즉시 반영.
3. **[결정 D4 → 착수, L] 정수 시스템** — 지금은 레벨업 때 "정수 슬롯 N" 문구뿐. 획득·장착·능력치/스킬 효과 전부 없음. 기획서 `docs/design/05_monsters_essence.md` 6-4 참고.
4. **[착수, L] 생존 수치(포만감·수분·피로도)와 밤친구** — 캐릭터 창에 "준비 중" 자리만 있음. `docs/design/09_survival.md`. 착수 전에 감소 속도·배신 확률 공식 등 수치 설계 필요(부록 B-③).
5. **[보류, M] 기습·급소 변수 반영 후 재조정** — 고블린 덫·암흑지역·급소 피격(즉사)이 들어오면 고블린 99%·구울 94% 가 깎이므로 다시 측정.

## 5. 알려진 문제
