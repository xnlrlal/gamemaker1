## 부록 C. 개정 이력 (2026-10-12 ~ 10-14)
- 용어 일괄 교체: 마나 → 영혼력, 체력 → 생명력(마나감응도는 유지).
- 4-2의 덱·카드 서술을 4-9 쿨타임 방식에 맞춰 정리.
- 12-1을 "1차 구현(동료 1명)"으로 재정의해 12-2의 5인 확정과 정합.
- 머리말의 수치 원칙을 실제 본문에 맞게 수정(본문 수치 = 현재 구현값·마스터 원문).
- 손재주·인내심 재정의를 5-6절에서 확정·이관: 방어 경감 = 물리내성, 재생 = 자연재생(종족 표·성인식 장비·몬스터 공식·숙련·NPC 값 이관, 스케일은 재검증).
- (v4) 엔진을 GameMaker로 확정. 1-5 개발 순서를 출시 최소 버전 기준으로 재편하고 1-6 출시 범위를 신설. 16장에 GameMaker 구현 방향 추가.
- (v5) "2D 전환" 단계를 삭제: 처음부터 2D로 제작, 맵=실시간 이동 / 전투=턴제 화면 확정. 1-5 로드맵 재편, 16장을 "2D 구현과 출시"로 개정(터치 조작·서버 없음 명시), 7장 재설계 필요 항목을 18장에 추가.
- (v6) 표지·한 장 요약·읽는 법·용어집·목차를 추가하고, 부록 A(확정 결정 로그)와 부록 B(단계별 착수 체크리스트)를 신설. 고정값은 DB에서 읽는다는 원칙을 명시.

- (v7) 프로토타입(브라우저)을 만들며 확정: **맵 이동도 턴제(1칸=1턴), 전투는 지도 위에서**, 이동마다 재사용 대기 −1, 적은 지도에 보이고 여러 마리 동시 전투, 무기 사거리·시선(4-12 신설), 이동하면 턴 종료(후퇴 안전), 몬스터 진영 배치와 날짜별 무리 1·2·3마리(7-1), 확률 조우·순차 무리 전투·자동전투(예상 승률) 폐기/재설계, UI 방향(석재 창·핫바·횃불 시야) 추가, 적 타겟팅 재검토(12-2).
- (v7 열린 질문 확정, 2026-10-14) 자동전투는 (b) 잠정, 적 타겟팅은 거리+위협, 무리 크기는 나타날 때 현재 날짜로 재계산, 선공은 현재 규칙 유지, 미궁 시계는 현실 시간 유지, 인간형 NPC는 별도 이벤트, 2층 수치는 구현 때 결정.
