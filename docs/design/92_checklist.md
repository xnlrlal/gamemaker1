## 부록 B. 단계별 착수 체크리스트

각 단계를 시작하기 전에 정해야 할 항목이다. 상세 목록은 18장.

| 단계 | 참조 | 착수 전 정할 것 |
|---|---|---|
| ① 전투 코어 | 4장, 5장 | 쿨타임 값, 영혼력 회복량, 물리내성 스케일과 방어 경감 계수, 몬스터 스킬 세트(현재 DB는 임시로 베기만) |
| ② 1층 맵 이동·전투 | 4-12, 7-1, 7-2, 16 | (프로토타입에서 구현됨) 암흑지역 처리, 고블린 덫 판정, 1층 규모(개미굴), 자동전투 재설계 |
| ③ 생존 수치·밤친구 | 10장 | 수치별 감소 속도, 피로도 0일 때 디버프, 배신 확률 공식, 담요 역할 |
| ④ 동료·장비 | 8-1, 11장, 12장 | 동료 확보 방법, 역할 구분, 투구(즉사 대응), 근력 기반 파지 임계값 |
| ⑤ 저장/이어하기 | 2-2, 15 | 전투 도중 상태 복원 범위, 저장 슬롯 정책(캐릭터 1개 원칙과의 관계) |
| ⑥ 2층 | 7-3 | 지도 방식, 별빛 광원 아래의 암흑지역, 덫 설계, 짐승의 소굴 공격속도 |
| ⑦ 모바일 점검 | 16 | 터치 조작 방식, 세로 화면 UI, 플랫폼 요건·라이선스 |
| ⑧ 아트 교체·출시 | 16 | 원작 설정에서 가져온 고유명(라프도니아, 카르논 등)의 사용 권리 확인 |
