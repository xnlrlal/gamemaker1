## 한 장 요약

**어떤 게임인가**
주인공은 원래 이 게임을 플레이해 본 사람이다. 어떤 계기로 게임 속 세계에 들어와 거대한 미궁에 도전한다. 게임에서는 단순했던 어둠·허기·동료·함정이 이 세계에서는 생존을 좌우하는 위험이 된다. 한 번 죽으면 모든 것을 잃는다.

**핵심 재미 5축**

| 축 | 한 줄 |
|---|---|
| 영구 사망의 긴장 | 전투에서 지면 캐릭터와 모든 진행이 초기화된다 |
| 시간 압박 | 미궁 시계가 흐르고, 때가 되면 강제로 쫓겨난다 |
| 성장과 빌드 | 몬스터의 정수를 흡수해 능력과 스킬을 얻되, 슬롯과 해제 기회는 극히 제한적이다 |
| 신뢰의 위험 | 동료·밤친구·다른 탐험가는 도움이자 위협이다 |
| 지식의 가치 | 약초 식별, 몬스터 숙련, 지형 기억이 곧 생존력이다 |

**한 판의 사이클**

```
[캐릭터 생성] → [마을] → [입장 판단창] → [미궁 탐험]
                  ↑                          │ 이동·전투·획득
         환전·구매·정비                       ↓
                  └──── 강제 귀환 ←──────────┤
                                             └→ 사망: 전부 초기화 → 새 캐릭터
```

**1.0 출시 범위**
- 포함: 1~2층, 바바리안, 지도 위 턴제 쿨타임 전투, 정수, 생존 수치와 밤친구, 영구사망·강제 귀환·이어하기 저장, 동료 1~2명, 서버 없는 오프라인 싱글
- 출시 후: 3층 이상, 5인 파티, 길드·클랜·레이드, 마을 14구역, 잠긴 4개 종족

## 읽는 법

**표기**
- **[확정]** 확정된 설계 / **[마스터]** 원작 마스터 설정 근거 / **[미정]** 결정 필요
- 본문의 수치(종족 표, 장비 보너스, 정수 원문 값 등)는 **임시값 또는 마스터 원문**이며 확정값이 아니다. 실제 구현에서는 모든 고정값을 DB(`dungeon_stone.db`)에서 읽는다.
- **[확정, v7]** 표시는 v6 이후 프로토타입을 만들며 사용자가 확정한 변경이다(지도 위 턴제 전투 등).
- 이전 검증의 참고 결과(3-2 등)는 GameMaker 구현 후 다시 확인한다.

**용어**

| 용어 | 뜻 |
|---|---|
| 라프도니아 성채 | 무대. 마녀가 바깥 세계를 오염시켜 사람들이 성벽 안에 갇혀 산다 |
| 미궁 | 성채 아래의 거대한 던전. 탐험가의 생계 수단 |
| 탐험가 | 미궁에 도전하는 사람들. 서로 함부로 접근하지 않는 것이 불문율 |
| 마석 | 몬스터에게서 자주 나오는 자원. 환전소에서 스톤으로 바꾼다 |
| 스톤 | 화폐. 드랍되지 않고 환전으로만 얻는다 |
| 정수 | 몬스터에게서 극히 드물게 나오는 힘의 결정. 흡수하면 능력치와 전용 스킬을 주고 영구 장착된다 |
| 영혼력 | 전투 자원이자 그 최대치 (구 마나) |
| 생명력 | 체력 (구 HP) |
| 강제 귀환 | 정해진 체류일이 지나면 전투 중에도 마을로 돌려보내지는 것. 사망이 아니다 |
| 판단창 | 정해진 주기에 뜨는 "미궁에 들어갈 것인가" 선택창 |
| 밤친구 | 야영 중 서로를 지켜주는 임시 협력 관계. 배신할 수 있다 |
| 전투불능 | 인간형 NPC가 생명력 0이 되었을 때의 상태. 죽지 않고 선택이 갈린다 |

## 1. 게임 개요

### 1-1. 한 줄 소개
거대한 미궁에 도전하는 탐험가의 생존 서바이벌 RPG. 한 번 죽으면 모든 것을 잃는다.

### 1-2. 서사와 핵심 긴장
- 주인공은 원래 이 게임을 실제로 플레이해본 사람이며, 어떤 계기로 게임 속 세계에 들어오게 된다.
- 핵심 긴장은 **"게임 지식 vs 실제 위험도의 괴리"** — 게임에서는 단순했던 시스템(어둠, 허기, 동료, 함정)이 이 세계에서는 생존을 좌우하는 위험이 된다.

### 1-3. 세계관
- 무대는 **라프도니아 성채**. 수백 년 전 마녀가 바깥 세계를 오염시켜, 사람들은 성벽 안에 갇혀 산다.
- 성채 아래의 거대한 미궁에서 탐험가들은 마석과 정수를 얻어 살아간다. 바바리안에게는 사실상 유일한 생존 수단이다.
- 왕궁(황도 카르논)과 반왕궁(지하 시설)의 대립 구도가 있다(상세 미정).
- 탐험가들 사이에는 "서로 함부로 접근하지 않는" 불문율이 있다. 서로가 잠재적 위험이기 때문이다.
- 성인은 모두 납세 의무가 있고 미납하면 사형이다. 바바리안은 평범한 노동이 불가능해 미궁 수입 의존도가 특히 높다.

### 1-4. 핵심 재미 축
1. **영구 사망의 긴장** — 전투에서 지면 모든 것이 초기화된다.
2. **시간 압박** — 미궁 시계가 흐르고, 오래 머물수록 위험해지며, 때가 되면 강제로 쫓겨난다.
3. **성장과 빌드** — 몬스터의 정수를 흡수해 능력과 고유 스킬을 얻되, 슬롯과 해제 기회는 극히 제한적이다.
4. **신뢰의 위험** — 동료·밤친구·다른 탐험가는 도움이자 위협이다.
5. **지식의 가치** — 약초 식별, 몬스터 숙련, 지형 기억 같은 "알고 있음"이 곧 생존력이다.

### 1-5. 최종 목표와 개발 순서
- 최종 목표는 **2D 탑다운 게임으로 앱 스토어에 출시**하는 것이다. 엔진은 **GameMaker(GML) [확정]**.
- **처음부터 2D로 만든다** [확정]. 텍스트 버전을 먼저 만들고 화면만 바꾸는 "2D 전환" 단계는 두지 않는다. 아트는 임시 그래픽(단색 도형)으로 시작하고 마지막에 교체한다.
- **맵 이동도 턴제, 전투는 지도 위에서** [확정, v7]: 한 칸 이동 = 한 턴이고 별도의 전투 화면은 없다. 적은 지도에 미리 보이고(시야 안) 여러 마리가 동시에 싸운다. **스킬·공격의 재사용 대기는 턴 단위이며 이동 한 칸마다 1씩 줄어든다**(4-9, 4-12). 미궁 시계(강제 귀환)는 턴과 별개로 현실 시간으로 흐른다.
- **출시 우선순위(최소 버전)** [확정]: ① 전투 코어(턴 단위 쿨타임, 지도 위 전투, 로직은 script로 분리, 값은 DB에서 조회) + 밸런스 검증 → ② 1층 턴제 맵 이동·미궁 시계·몬스터 배치와 경계 → ③ 생존 수치(포만감·수분·피로도)와 밤친구 → ④ 동료(1~2명), 투구 등 장비 마무리 → ⑤ 저장/이어하기 → ⑥ 2층 → ⑦ 모바일 빌드와 터치 조작 최종 점검 → ⑧ 아트 교체와 출시.
- 맵 이동이 만들어지는 ② 시점부터 실기기에서 터치 조작을 수시로 검증한다.
- **출시 후**: 3층 이상, 5인 파티, 탐험가 약탈 확장, 마을 14구역·경제, 탐험가 길드, 클랜, 레이드, 스킬 확장.

### 1-6. 출시 범위 [확정]
**포함**
- 1~2층, 바바리안 단일 종족
- 지도 위 턴제 쿨타임 전투, 부위 손상 (자동전투는 재설계 후 — 4-10)
- 정수 시스템(구현 가능한 정수부터)
- 생존 수치 3종과 밤친구
- 영구사망, 강제 귀환, 이어하기 저장
- 동료 1~2명
- 인간형 NPC 조우(동료로 삼기 / 살려주기 / 끝장내기까지)
- 마을은 상점·신전·환전소
- 서버 없이 오프라인 싱글 플레이

**제외 (출시 후)**
- 3층 이상, 5인 파티, 길드·클랜·레이드
- 마을 14구역, 경매장, 혼령각인
- 잠긴 4개 종족
- 몬스터 100종 목표(출시는 현재 18종 + 소수 추가)

**주의**
- 연간 세금은 3층 이후에 켜므로 출시 버전에서는 꺼져 있다. 시간 압박은 강제 귀환과 생존 수치가 맡으므로 이 둘이 최소 버전의 핵심이다.
- 수치 재검증은 쿨타임 전환 직후 한 번에 끝내고, 이후 기능을 얹을 때마다 다시 하지 않는다.

## 17. 설계 원칙

1. **영구 사망 우선**: 새로 추가되는 모든 상태(호감도·퀘스트·생존 수치·탐험가 등급·식별 지식 등)는 사망 시 예외 없이 초기화된다.
2. **출처가 아니라 상태로 판단**: 아이템이 "미궁 한정인가 영구 보유인가"는 어디서 얻었느냐가 아니라 지금 상태로 정한다(나중에 스킬·스크롤·약탈 등으로 전환 가능하도록).
3. **상한이 있는 성장**: 확률형·배율형 능력치에는 항상 상한을 둔다(명중, 방어, 치명타, 독 경감, 즉사, 행동 횟수) — 무적과 무한 성장을 막는다.
4. **근거 없는 수치는 임시값으로 취급**하고, 서사적 근거 없이 몬스터 속도나 등급을 올리지 않는다.
5. **불확실하면 안전한 쪽으로**: 일반적으로 보존이 안전하지만 사안에 따라 "안전"의 정의가 다르다.
6. **시스템은 서로 연결되게 설계**: 밤친구 배신 → 전투불능 → 약탈, 위협 수치 → 거대화·야성분출·탱커 역할, 마석 → 환전·유전·세금처럼 한 요소가 여러 시스템을 관통한다.
7. **보이지 않는 정보는 보이지 않게**: 안 가본 지형은 존재 자체를 드러내지 않고, 안개와 지도는 별개로 다룬다.
8. **한 요소가 다른 요소를 압도하지 않게**: 영혼력이 행동 수를 결정하던 구조, 방어가 승부를 지배하는 구조 같은 쏠림을 경계한다.
9. **이동과 행동에 같은 규칙**: 플레이어와 몬스터 모두 한 턴에 이동하거나 행동한다. 한쪽에만 "이동 + 공격"을 허용하면 후퇴·접근의 의미가 깨진다(빠른 몬스터에게서 물러서도 맞던 사례). [v7]
