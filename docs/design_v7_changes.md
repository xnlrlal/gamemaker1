## 열린 질문 7개 — 확정 결과 (2026-10-14)
1. **자동전투(4-10)**: (b) 가장 가까운 적을 최선의 스킬로 공격만 반복. 사용자가 선호를 정하지 않아 추천안을 **잠정** 채택. 예상 승률 표시는 폐기.
2. **적 타겟팅(12-2)**: **거리 + 위협(어그로) 수치**. 위협의 정의·가중치는 동료 구현 때.
3. **무리 크기 시점**: **항상 현재 날짜로 재계산**(나타나는 순간 기준). 코드(`tactics.js`)는 이미 나타나는 순간의 날짜로 크기를 정하므로 구현 변경은 없다.
4. **선공 규칙**: 현재 규칙 유지(먼저 붙는 쪽이 맞음, 보정 없음).
5. **시간 압박**: 미궁 시계는 현실 시간 유지.
6. **인간형 NPC**: 진영 배치가 아닌 **별도 이벤트**. 발생 조건·연출은 미정.
7. **2층**: 진영 밀도·무리 크기는 2층 구현 때 결정.

## 반영 방식
- 수치는 `data/db.json` 의 값이 현재 임시값의 기준이다. 기획서 본문의 수치는 여전히 "임시값" 취급.
- 구현 쪽 상세와 검증 결과는 `docs/implementation_notes.md`, 전체 흐름은 `CHANGELOG.md`.
